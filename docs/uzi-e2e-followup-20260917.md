可以确认原来的文档视图缺少显式当地日期。

- 报告研究和数据中心证据整理共享纯转换函数；增加 `published_at_market`、
  `market_publication_date`、`market_timezone` 展示值，保留原 `published_at`。
- 时区必须已知，原时刻必须有明确时区；缺失、仅日期或无时区旧值不臆造转换。
- `visible_by` 继续只是观察上界，不能成为首次发布日期；未知发布日期不回填。
- 提示明确区别发布日期、事件发生日、报告期和文件落款；不新增模型内容硬门禁。
- 原本的窄来源时间冲突检查使用当地日期，避免把 UTC 跨日误当作事实矛盾。
- 仅修改模型只读视图，没有修改归档正文、证据表、旧 Manifest 或旧报告。

### 4. 错误的宿主引用 ID 提前截断新来源补证

本轮日志出现 `qualitative_archive_binding_unknown`／`ambiguous` 和事实引用缺 URL。
其中具体首次模型值未保留，不能断言全部来自同一原因。代码核对可确定一个不一致：

原生 Task 2.5 的来源 schema 没有 `evidence_id`，这是本地的可选元数据提示。

- 未知 ID 配新 URL 与原生 URL-only 路径一致：清除失效的宿主提示，保留 URL 和 finding。
- 后续仍提取补证请求并拒绝未归档 URL，不能因此算作已验证来源。
- 原生允许的 `source=unknown` 无 URL 缺口披露，不能被一个错误可选 ID 拒绝，也不能生成虚假归档时间。
- 已知 ID 冲突、不同原件内容版本的歧义、普通事实缺 URL 等保护不取消；不把事实强改为 unknown。
- 只读研究提示明确区分阅读 `document_id` 与引用 `evidence_id`，后者只能来自 `archive_bindings`。
- 来源绑定、引用修复、定性分析及补证范围 58 项回归通过。该修复同样未部署到当前活动批次。

使原生 URL-only 引用被判 `qualitative_archive_binding_ambiguous`。
