修复方向：完整传递固定证据的 ID、URL、正文、hash 和版本依据；按证据身份去重，不用合成来源覆盖真实引用。

安全断言应核对既有证据是否在传递中丢失，不是恢复“启动前必须两个 URL”的额外研究门槛。
