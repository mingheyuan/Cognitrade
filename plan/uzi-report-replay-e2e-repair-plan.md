- 原生三档“值得重仓／可以蹲一蹲／可以蹲（偏弱）”许可新开仓；直接读取原始评级，不从显示分数重算。

- D 日报告从下一交易日收盘开始评估；入场为 close <= entry 且未触发 stop，退出为 close <= stop 或 close >= target。次一有效交易日按真实 open 成交；待买开盘已越过 stop/target 则取消，不按阈值美化成交。
- 开仓许可为生效日起三个交易日（含生效日），新报告只替换未入场计划。已有仓位锁定建仓报告的退出计划直到平仓；缺报告/过期/新评级不凭空清仓或放宽止损。
- 每个计划仅一次首批；基金披露股票池不由报告成功列表决定。缺报价不以零估值或删除持仓，缺开盘不补收盘。
