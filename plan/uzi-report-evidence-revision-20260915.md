# 报告研究可补证、输入版本不可变

## 边界

研究过程中允许扩大资料集合；不可变的是每次实际分析/交付所引用的输入版本。
新资料由数据中心核实、归档并产生快照/Bundle/Manifest 修订，绝不原地改旧报告。
历史资料仍需通过截止日可见性检查；自动补采和订阅保持关闭。

## 本轮实施

1. 把未绑定的定性引用记录为待核实资料，和普通模型格式错误区分。保留受影响维度、可安全归档的 URL 及内容指纹；不把未核实引用直接当证据。
2. 补证计划包含明确的目标 URL，送入显式数据中心任务；已有文档不能导致新目标被跳过，也不能只重新解析旧原文。
3. 复用数据中心原文校验、历史可见性与新快照持久化。模型提供的日期、标题或不可变性声明不构成历史证明。
4. 前端提供查看补证方案、显式启动补采、查看任务进度和使用已归档新输入修订报告的入口。保留原数据重试路径，不自动重采基金持仓。
5. 复用现有 Manifest 局部修订：选择已补齐股票；其他股票的证据、顺序、权重和旧 Manifest 保持不变。

## 验收

- 发现新来源不会隐式联网或直接获得交付许可，而是产生可执行补证请求。
- 只有显式采集请求才获取指定公开 URL；拒绝私有地址、凭据 URL、越界维度和未核实的历史版本。
- 定向原文补采可以突破已有归档的复用判断，成功后新增快照并保留旧内容。
- 新 Manifest 读取新增原文，旧 Manifest 重放不变；未受影响股票不重采。
- 后端必要回归及前端交互测试；真实验证保留来源失败，不伪造报告成功。

本轮不包含正文异常持续输出的独立修复，也不把 URL 归档成功等同事实结论已核验。
